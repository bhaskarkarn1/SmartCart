Pipeline

How SmartCart thinks

Six intelligent stages from raw data to personalized top-3 recommendations.

01

Data Ingestion

Parses 1.4M order records with JSON-embedded item details from real transaction data.

02

Item Tagging

Classifies 138 items into main, side, dip, drink, and other categories automatically.

03

Co-occurrence Matrix

Computes conditional probability P(j|i) for all item pairs using normalized frequencies.

04

Scoring Engine

Aggregates co-scores with soft bias for underrepresented categories and spicy-aware bonuses.

05

Diversity Filter

Ensures max 1 recommendation per type — no duplicate categories in your suggestions.

06

Top-3 Output

Final ranked suggestions using global popularity fallback when co-occurrence data is sparse.
